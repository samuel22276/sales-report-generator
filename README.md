# Sales Report Generator

A Python-based sales data analysis and automated Excel reporting tool.

This project takes raw sales data from a CSV file, analyzes sales performance using Python and pandas, and generates a professional Excel report with KPIs, summaries, and charts.

## Features

- CSV sales data processing
- Automated revenue calculations
- Data validation
- Total revenue and units sold calculations
- Average order value calculation
- Product revenue analysis
- Regional revenue analysis
- Monthly revenue analysis
- Automated Excel report generation
- Excel dashboard with KPI metrics
- Revenue charts by product and region
- Professional spreadsheet formatting

## Technologies

- Python
- pandas
- openpyxl
- Matplotlib
- CSV
- Microsoft Excel
